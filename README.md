# Foodies - Backend API

This repository contains the Django backend for the Foodies application, a unified platform for food, grocery, and pharmacy delivery.

This project provides the foundational boilerplate including:
- A multi-app architecture (`users`, `restaurants`, `orders`, `chat`, `analytics`).
- Data models as per the project specification.
- Placeholder API endpoints using Django REST Framework.
